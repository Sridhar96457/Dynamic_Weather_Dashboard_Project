# 🌤️ Dynamic Weather Dashboard  

---

## 📌 Project Overview  
The **Dynamic Weather Dashboard** is a responsive and lightweight web application that provides **real-time weather updates** and a **5-day forecast** for any city worldwide.  
It uses the **OpenWeatherMap API** and is built entirely with **HTML**, **CSS**, and **JavaScript** — no frameworks, no backend.  

The dashboard focuses on simplicity, interactivity, and mobile-first design, making it perfect for quick access to weather insights from any browser.  

---

## ✨ Features  

- 🌍 Get real-time weather for any city  
- 📍 Fetch weather using your **current location**  
- 🕔 Display **5-day forecast** with temperature and weather conditions  
- 🧩 Lightweight, clean, and responsive user interface  
- ⚠️ Error handling for invalid city names or denied location access  
- 🚀 Can be hosted easily on **GitHub Pages** or **Netlify**

---

## 🧠 How It Works  

1. User enters a **city name** or clicks **Use My Location**.  
2. The app fetches **current weather** and **5-day forecast** from OpenWeatherMap API.  
3. Data is processed by `script.js` and displayed dynamically in the browser.  
4. All results are shown in a clean, responsive layout created with `style.css`.
